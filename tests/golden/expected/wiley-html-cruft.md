# Biodiversity Assessment Using Environmental DNA

## Abstract

Environmental DNA (eDNA) metabarcoding provides a **non-invasive** method for surveying aquatic biodiversity.

## Introduction

Traditional biodiversity surveys require specimen collection, which can be logistically challenging and *destructive* to sensitive habitats.

## Methods

Water samples were filtered through 0.45 μm cellulose nitrate filters. DNA was extracted using the DNeasy PowerWater Kit.

### Primer Selection

We used the MiFish-U primer set targeting the 12S rRNA gene for fish detection and the mlCOIintF/jgHCO2198 pair for invertebrates.
