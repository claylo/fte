# Introduction to Quantum Error Correction

## Abstract

Quantum error correction protects quantum information against **decoherence** and **operational errors**.

## Surface Codes

The surface code is the leading candidate for fault-tolerant quantum computation due to its *high threshold* and nearest-neighbor connectivity requirements.

### Logical Qubits

A distance-d surface code encodes one logical qubit in d^2 physical qubits.

### Error Thresholds

Below the threshold error rate p_th ≈ 1%, logical error rates decrease exponentially with code distance.
